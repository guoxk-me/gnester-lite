# Internationalization / 国际化

## Mental model

- Language negotiation uses `Accept-Language` only (`en`, `zh`; fallback `en`).
- Success and failure share one JSON envelope:
  `{ code, message, data, errors }`.
- `code` matches the HTTP status. `message` and validation `errors[].reason`
  are localizable. Clients must branch on `code`, not on `message` text.
- `CommonI18nModule` registers the envelope interceptor/filter.
  `I18nCatalogModule` loads translation JSON for any consumer that needs
  `I18nService` without HTTP wrapping side effects.

## Key files

- `src/platform/runtime/i18n/` — module, interceptor, filter, locales
- `src/contracts/api-envelope.ts` — shared envelope type
- `src/bootstrap/http/validation.pipe.ts` — validation details inside the envelope
- `nest-cli.json` — copies `platform/runtime/i18n/locales/**/*` into `dist`

## Opt-outs

Use `@SkipApiEnvelope()` for Terminus health probes. SSE (`Observable`) and
`StreamableFile` responses are skipped automatically.

## Adding copy

1. Add keys under `src/platform/runtime/i18n/locales/{en,zh}/`.
2. Translate with `I18nService.t('namespace.key')` or throw an i18n key as an
   `HttpException` message for the exception filter to resolve.
